Azure User and Access Management
 
Project Type
 
Practice Project
 
Objective
 
To understand how user accounts, groups, and access permissions are managed in Microsoft Azure and Microsoft Entra ID.
 
Tasks
 
Create and manage user accounts.
- Create security groups and add users.
- Assign and revoke Microsoft 365 licenses (such as E5).
- Manage user licenses through the Microsoft 365 admin center and Azure portal, where applicable.
- Handle license changes during user onboarding and offboarding.
- Understand role-based access control (RBAC).
- Review user access and permissions.
- Support user onboarding and offboarding procedures.
- 
Tools
 
- Microsoft Azure
- Microsoft Entra ID
 
Learning Outcomes
 
- Understanding identity and access management.
- Learning user and group administration.
- Understanding access control and security practices.
